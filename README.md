# Fysiikan loppuprojekti – GPS- ja kiihtyvyysanalyysi

Tämä projekti on fysiikan kurssin loppuprojekti, jossa analysoidaan liikkeen kiihtyvyyttä ja GPS-sijaintia Pythonilla. Projektissa hyödynnetään Streamlit-käyttöliittymää datan visualisointiin.

## Projektin rakenne

/
├── app.py
├── generate_data.py
├── data/
└── README.md

## Ominaisuudet

- GPS-datan ja kiihtyvyyden analysointi
- Datan generointi simuloidulle liikkeelle
- Interaktiivinen Streamlit-käyttöliittymä
